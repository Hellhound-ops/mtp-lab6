## Запуск

Нужен Python 3.12. В PowerShell выполните команды из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Откройте `http://127.0.0.1:5000`. Для Bootstrap требуется доступ к CDN.
Статическая страница и каталог доступны сразу.

## Учебный пользователь

Остановите сервер, сгенерируйте хеш пароля и ключ сессии:

```powershell
.\.venv\Scripts\python.exe -m flask --app main make-credentials
$env:LAB_USER = 'student'
$env:LAB_PASSWORD_HASH = '<скопируйте значение после LAB_PASSWORD_HASH=>'
$env:SECRET_KEY = '<скопируйте значение после SECRET_KEY=>'
.\.venv\Scripts\python.exe main.py
```

Войдите на `/login` с выбранным паролем. Кабинет доступен после входа,
кнопка выхода завершает сессию. Секреты хранятся в переменных окружения.
Формы входа и выхода проверяют токен CSRF. В приложении одна учебная учётная запись.

## Демонстрация на ревью

1. Откройте главную страницу, затем страницу `/bootstrap` и каталог `/catalog`.
2. Перейдите в `/account`. Без активной сессии приложение откроет форму входа.
3. Войдите как учебный пользователь из предыдущего раздела. Проверьте кабинет и кнопку выхода.
