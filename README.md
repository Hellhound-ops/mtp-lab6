## Локальный запуск для ревью

Нужен Python 3.12. Выполните команды в PowerShell из папки проекта.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py --demo
```

1. Откройте [главную страницу](http://127.0.0.1:5000/), затем [страницу Bootstrap](http://127.0.0.1:5000/bootstrap) и [каталог Jinja2](http://127.0.0.1:5000/catalog). Для загрузки стилей Bootstrap нужен доступ к CDN.
2. Перейдите в [личный кабинет](http://127.0.0.1:5000/account). Форма входа принимает имя `student` и учебный пароль `lab6-demo`.
3. Проверьте, что открывается кабинет. Нажмите «Выйти» и снова откройте кабинет, чтобы увидеть форму входа.

Режим `--demo` слушает только `127.0.0.1` и создаёт ключ сессии при каждом запуске.

## Запуск со своим учебным пользователем

Остановите сервер и выполните команду для генерации хеша пароля и ключа сессии.

```powershell
.\.venv\Scripts\python.exe -m flask --app main make-credentials
$env:LAB_USER = 'student'
$env:LAB_PASSWORD_HASH = '<скопируйте значение после LAB_PASSWORD_HASH=>'
$env:SECRET_KEY = '<скопируйте значение после SECRET_KEY=>'
.\.venv\Scripts\python.exe main.py
```

Войдите на `/login` с выбранным паролем. Кабинет доступен после входа,
кнопка выхода завершает сессию. Секреты хранятся в переменных окружения.
Формы входа и выхода проверяют токен CSRF. В приложении одна учебная учётная запись.
